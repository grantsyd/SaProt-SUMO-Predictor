SaProt-SUMO-Predictor

本项目为本科毕业设计“基于深度表征与集成学习的类泛素化位点预测”的相关代码和模型文件。项目围绕蛋白质类泛素化修饰（SUMOylation）位点预测任务展开，主要利用蛋白质语言模型 SaProt 提取候选赖氨酸残基附近序列片段的深层特征，并结合自编码器降维、重采样策略和集成学习模型进行分类预测。

项目简介

类泛素化修饰是蛋白质翻译后修饰中的一种重要形式，通常发生在底物蛋白的赖氨酸残基上。由于实验鉴定类泛素化修饰位点通常存在成本较高、周期较长和难以大规模筛选等问题，因此可以借助计算方法对候选修饰位点进行预测，为后续实验验证提供参考。

本项目主要实现以下内容：

构建以候选赖氨酸残基为中心的 41-mer 序列窗口；
使用 SaProt 蛋白质语言模型提取候选序列的深层特征；
采用自编码器对高维 SaProt 特征进行降维，得到 SaProt-AE384 特征表示；
针对正负样本不平衡问题，引入 SMOTE-ENN 和 NearMiss 等重采样策略；
比较 LightGBM、XGBoost 和 ExtraTrees 等树模型；
构建加权 SoftVoting 集成模型，实现类泛素化修饰位点预测。
方法流程

本项目整体流程如下：

数据集构建
→ 41-mer 候选序列窗口构建
→ SaProt 深层特征提取
→ AE384 降维处理
→ 重采样处理
→ LightGBM / XGBoost / ExtraTrees 模型训练
→ 加权 SoftVoting 集成
→ 输出候选位点预测结果

环境配置

建议使用 Python 3.8 及以上版本。

安装依赖：

pip install -r requirements.txt

主要方法说明

本项目以 SaProt 蛋白质语言模型作为主要深层特征提取工具。对于每个候选样本，首先以赖氨酸残基为中心构建固定长度的 41-mer 序列窗口，然后利用 SaProt 提取候选序列片段的上下文特征。考虑到原始 SaProt 特征维度较高，项目进一步采用自编码器进行非线性降维，将高维特征压缩为 384 维潜在表示，即 SaProt-AE384 特征。

在样本处理方面，项目根据不同数据集的特点采用不同重采样策略。对于小样本且类别不平衡程度较高的数据集，采用 SMOTE-ENN 方法进行样本平衡；对于样本规模较大的数据集，采用 NearMiss 方法筛选多数类负样本，以缓解类别不平衡对模型训练的影响。

在分类模型方面，项目比较了 LightGBM、XGBoost 和 ExtraTrees 等树模型，并进一步采用加权 SoftVoting 方法融合多个基分类器的预测概率，以提高模型预测稳定性。
